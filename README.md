# koti

Local-first home automation toolkit. This monorepo hosts unofficial Ruby SDKs, one per
ecosystem, each published as its own gem and working on the local network.

| Gem | Ecosystem | Status |
|---|---|---|
| [`hue-sdk`](hue-sdk) | Philips Hue (CLIP API v2) | In progress |
| `miele-sdk` | Miele@home | Planned |
| `sauter-sdk` | Sauter / Atlantic Cozytouch | Planned |
| `google-home-sdk` | Google Nest / Google Home | Planned |

These projects are not affiliated with, endorsed by or sponsored by Signify, Miele,
Groupe Atlantic or Google.
